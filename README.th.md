## ดาวน์โหลด

โหลด `VRCNook.exe` จาก [Release ล่าสุด](https://github.com/iriewiew/vrc-nook/releases/latest) แล้วเปิดได้เลย ไม่ต้องติดตั้ง
ควรวางไว้ในโฟลเดอร์ที่เขียนไฟล์ได้ เช่น Documents อย่าวางใน Program Files เพราะแอปอัปเดตตัวเองโดยเขียนทับไฟล์เดิม

**ต้องใช้:** Windows 10/11 ที่มี Microsoft Edge WebView2 (Windows 11 มีอยู่แล้ว)

## ฟีเจอร์

### เพื่อนและโซเชียล
- **รายชื่อเพื่อนแบบ real-time** ผ่าน WebSocket ของ VRChat แบ่งกลุ่มเป็น: อยู่ในโลกสาธารณะ, อยู่ในโลกส่วนตัว, ออนไลน์บนเว็บ และออฟไลน์
- **มุมมอง:** เปลี่ยนมุมมองได้ และดูได้ว่าเพื่อนแต่ละคนออนไลน์ล่าสุดเมื่อไร
- **การ์ดโปรไฟล์:** แสดง banner, กรอบโปรไฟล์, badge, bio, ลิงก์, เพื่อนร่วมกัน และประวัติการเปลี่ยนชื่อ
  - โน้ตส่วนตัวซิงก์กับ VRChat
  - ทำได้จากการ์ด: เชิญ, ขอ invite, Boop พร้อมอีโมจิ, เพิ่มรายการโปรด, บล็อก/ปิดเสียง
- **Feed:** ความเคลื่อนไหวของเพื่อน เช่น เปลี่ยนสถานะ, ย้ายโลก, เปลี่ยนอวตาร, เปลี่ยนชื่อ
- **การแจ้งเตือน:** คำเชิญ, คำขอเป็นเพื่อน และแจ้งเตือนจากกลุ่ม ตอบกลับด้วยข้อความสำเร็จรูปได้ (แนบรูปได้ถ้ามี VRC+)
- **แจ้งเตือนของ Windows** และไอคอนที่ถาดระบบ ตั้งให้เปิดพร้อม Windows ได้

### Game Log
- **อ่าน log ของ VRChat แบบ real-time:** เข้าโลก, คนเข้า/ออก, วิดีโอ, การถ่ายรูป, สติกเกอร์, หลุดการเชื่อมต่อ และอื่นๆ
- **ตัวกรอง:** เลือกได้ว่าจะแสดงเหตุการณ์ประเภทไหน
- **เก็บประวัติถาวร:** บันทึกลงฐานข้อมูล SQLite ในเครื่อง VRChat ลบ log เก่าเอง แต่ VRC Nook ยังเก็บไว้ให้
- **ประวัติโลก:** ทุกโลกและทุก instance ที่เคยไป พร้อมรายชื่อคนที่เจอ

### เนื้อหาใน VRChat
- **โลกและห้อง:** ดูโลก, สร้าง instance, เปิดโลกใน VRChat, ดูร้านค้าในโลก
- **รายการโปรด:** เพื่อน, โลก และอวตาร
- **อีเวนต์:** ปฏิทินอีเวนต์ของ VRChat และ Jams
- **กลุ่ม:** ดูและจัดการกลุ่ม ได้แก่ สมาชิก, คำเชิญ, คำขอเข้าร่วม, การแบน และห้องของกลุ่ม
- **อวตาร:**
  - เปลี่ยนอวตาร และดูขนาดไฟล์/ระดับประสิทธิภาพแยกตามแพลตฟอร์ม
  - ค้นหาอวตารสาธารณะผ่าน avtrdb.com
- **Inventory:** ไอคอน VRC+, รูปถ่าย, prints, อีโมจิ, สติกเกอร์ และ props
- **ค้นหา:** ผู้ใช้, โลก, กลุ่ม และอีเวนต์ วางลิงก์หรือ ID ได้เลย
- **บัญชีของฉัน:** แก้ bio, ลิงก์ และสถานะ จัดการรายการบล็อก/ปิดเสียง

### ทำอีโมจิเคลื่อนไหว
- **ไฟล์ต้นทาง:** GIF เคลื่อนไหว, WebP เคลื่อนไหว หรือรูปหลายไฟล์ (ไฟล์ละ 1 เฟรม)
- **ปรับแต่ง:**
  - เลือกช่วงเฟรมและจำนวนเฟรม
  - ลบพื้นหลังด้วย chroma key (คลิกที่ภาพตัวอย่างเพื่อดูดสี)
- **ผลลัพธ์:** แอปสร้าง sprite sheet ขนาด 1024×1024 ตามรูปแบบของ VRChat ให้อัตโนมัติ
- **ตัวอย่าง:** ดูแต่ละ animation style ด้วยภาพตัวอย่างทางการของ VRChat แล้วอัปโหลดได้ทันที

### แชทขึ้น Chatbox ในเกม (OSC)
- **หน้าแชท:** พิมพ์ในแอปแล้วข้อความขึ้น Chatbox ในเกม พร้อมประวัติการส่ง
- **สถานะ:** แสดงจุด "กำลังพิมพ์…" ในเกมระหว่างพิมพ์ เปิด/ปิดเสียงแจ้งเตือนได้

### คีย์บอร์ดบนจอสำหรับ VR
- **ออกแบบมาสำหรับ VR:** ปุ่มใหญ่ ปรับขนาดได้ มีปุ่มคัดลอก, วาง และเลือกทั้งหมด
- **แยกออกมาเป็นคีย์บอร์ดลอย:**
  - อยู่เหนือทุกหน้าต่าง และไม่แย่งโฟกัส
  - **โหมดแชทในเกม:** ส่งข้อความขึ้น Chatbox
  - **โหมดคีย์บอร์ดของ Windows:** พิมพ์ลงโปรแกรมไหนก็ได้ มีปุ่ม Task View
- **ภาษา:** ไทย, อังกฤษ, ฮิรางานะ/คาตาคานะ, เกาหลี, รัสเซีย, เวียดนาม, จีนพินอิน และอีโมจิ
  - ภาษาเกาหลีรวมพยางค์ให้อัตโนมัติ
  - ภาษาเวียดนามและพินอินมีปุ่มวรรณยุกต์
- **ตั้งค่า:** เลือกได้ว่าปุ่มสลับภาษาจะวนผ่านภาษาไหนบ้าง

### ปรับแต่ง
- **ภาษาของแอป 7 ภาษา:** ไทย, English, 日本語, 한국어, Русский, Tiếng Việt, 中文
- **ธีม:** สว่าง/มืด และกำหนดสีไล่ระดับเองได้
- **ฟอนต์:** Noto Sans Thai และฟอนต์ยอดนิยมจาก Google Fonts ปรับขนาดตัวอักษรได้
- **หน้าต่าง:** ตั้งให้อยู่บนสุด และย่อไปที่ถาดระบบได้

## ความเป็นส่วนตัวและความปลอดภัย

- **ไม่เก็บรหัสผ่าน** รหัสผ่านส่งตรงไปที่ VRChat
  - เก็บไว้แค่ session cookie ที่เข้ารหัสด้วย Windows DPAPI ถอดได้เฉพาะบัญชี Windows ของคุณ
- **cookie ส่งไปที่ `api.vrchat.cloud` เท่านั้น** ถ้าถูก redirect ไปโฮสต์อื่นจะตัด cookie ออกก่อน
- **ข้อมูลอยู่ในเครื่องทั้งหมด** ที่ `%APPDATA%\VRCNook`:
  - การตั้งค่า
  - ฐานข้อมูล game log
  - โน้ตและประวัติแชท
  - cache รูป
- **การเชื่อมต่ออื่น:**
  - [avtrdb.com](https://avtrdb.com): เฉพาะตอนค้นหาอวตารสาธารณะ และส่งไปแค่คำค้นหา
  - Google Fonts: เฉพาะตอนเลือกฟอนต์จากเว็บ
  - `assets.vrchat.com`: ภาพตัวอย่างเอฟเฟกต์
  - `api.github.com`: ตรวจอัปเดต

## โฟลเดอร์ข้อมูล

```
%APPDATA%\VRCNook\
├─ session.bin     การเข้าสู่ระบบ (เข้ารหัส)
├─ settings.json   การตั้งค่า
├─ data.db         game log, feed, โน้ต, ประวัติชื่อ, ประวัติแชท (SQLite)
├─ debug.log       log ข้อผิดพลาด
└─ cache\          รูปและข้อมูลโปรไฟล์ (ลบได้ เดี๋ยวโหลดใหม่เอง)
```

```powershell
python vrclog_mac.py          # รัน
.\build.ps1                   # สร้าง dist\VRCNook.exe
```
